Comparativa entre Software Libre/abierto y propietario:

El software libre, son códigos desarrollados en colaboración abierta, que lo puede consultar o modificar cualquier usuario.
En cambio para disponer de un software propietario, es necesario pagar para obtenerlo.

Que el FSF se llame así no significa que sea completamente gratuito, ya que tener un software y desarrollarlo puede tener costes adicionales.
